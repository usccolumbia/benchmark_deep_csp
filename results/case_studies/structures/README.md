CIFs behind the case-study structure figures (case_Co3Sb4O6F6, case_Ba6Al10). Panel (a) is the Materials Project reference; panels (b)-(f) are each method's rank-1 exported candidate from the T180 v3.1 campaign. File names carry rank, formula, method and candidate ID. Use manifest.csv for paths: it records the ranking basis, source path, match status and SHA256. The figures were drawn by scripts/new_t180_case_study_figures.py, which reduces the reference to its 0.01 A primitive cell.

The `primitive/` subfolder holds the same structures reduced to their primitive cells (tolerance 0.01 A), so that the reference and all predictions of a target open in VESTA with the same cell choice and atom count. Files keep their names; manifest.csv lists both versions (columns primitive_file, sites_primitive, sha256_primitive). The top-level CIFs keep the cell as exported by each method (the reference is the stored conventional cell).

The `aligned/` subfolder holds, for every structure that matches the reference, the primitive cell re-expressed in the reference's cell setting and origin (pymatgen StructureMatcher.get_s2_like_s1, no change to inter-site distances or to the structure's own lattice lengths and volume), so matching structures overlay the reference in VESTA (for example Uni-3DAR Ba6Al10 gamma 60 -> 120 deg). Structures that do not match (TCSPv3 for Ba6Al10; the four generative models for Co3Sb4O6F6) are not aligned and are kept only in primitive/ and the top level. manifest.csv columns: aligned_file, matches_reference_for_alignment.
